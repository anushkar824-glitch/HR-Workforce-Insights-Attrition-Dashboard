# HR Workforce Insights & Employee Attrition Predictor Dashboard

## Project Overview
This project uses Power BI to analyse employee workforce data, attrition patterns, and employee risk levels. It helps HR teams understand workforce trends and identify areas that may require attention.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Dataset
The project uses a synthetic dataset of 150 employees with 22 original columns, plus an Age Group column created in Power Query.

## Dashboard Pages
### 1. HR Workforce Overview
- Total Employees
- Attrition Count
- Attrition Rate
- Average Monthly Income
- Attrition by Department and Job Role
- Attrition Status analysis

### 2. Attrition Risk Analysis
- Average Job Satisfaction
- High-Risk Employees
- Work Mode analysis
- Employee Joining Trend
- Department Analysis Matrix
- Interactive filters

## Key Skills Demonstrated
- Data cleaning and transformation
- DAX measure creation
- KPI development
- Interactive dashboard design
- Workforce and attrition analysis

## Note
All employee records are synthetic and created for learning and portfolio purposes. The attrition risk categories are illustrative and are not produced by a validated predictive model.
